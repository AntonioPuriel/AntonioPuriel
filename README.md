# Antonio Puriel Hernández

Bioinformatician, PhD in Environmental Microbiology (Université de Pau et des Pays de l'Adour, 2025).
I build reproducible pipelines for high-throughput sequencing data and work closely with the people who generate it.

**What I do**
- Shotgun metagenomics: QC, assembly, binning, MAG recovery and annotation
- Single-cell transcriptomics in R: QC, integration, annotation, malignant-cell calling, pseudobulk DE, cell–cell communication
- Reproducible workflows on HPC/SLURM: Nextflow, R `targets`, Conda and containers, CI
- Statistics for high-dimensional count data; reports in R and Python
- Community metabolic modelling (COBRApy, MICOM)

**Projects**
- [hcc-singlecell](https://github.com/AntonioPuriel/hcc-singlecell): reanalysis of public scRNA-seq from human hepatocellular carcinoma (~68k cells, 10 patients). Composition-aware QC, Harmony integration, inferCNV with a leave-one-patient-out epithelial reference, tumour-associated macrophage states, progenitor-like tumour cells and a ranked list of tumour–myeloid mediators *(in progress)*
- [mag-pipeline](https://github.com/AntonioPuriel/mag-pipeline): Nextflow DSL2 pipeline from raw reads to quality-assessed MAGs, built for shared clusters with storage quotas
- [magreport](https://github.com/AntonioPuriel/magreport): R package to explore and report MAG recovery results ([docs](https://antoniopuriel.github.io/magreport/))

**Thesis**: [Microbial communities under oxic/anoxic oscillations in contaminated coastal sediments](https://hal.science/tel-05543123) (HAL)
